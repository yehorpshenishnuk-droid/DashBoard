# Kitchen Dashboard (Render + Poster API)

## 🔧 Инструкция

1. **Создай .env переменные в Render:**
   - `POSTER_TOKEN=твой_токен_от_Poster`
   - `CHOICE_TOKEN=твой_токен_от_Choice` (опционально)
   - `WEATHER_KEY=твой_ключ_от_OpenWeatherMap` (опционально)
   - `POWER_ADDRESS=твоя_адреса` (опционально, для статусу світла)

2. **Залей этот проект на GitHub**

3. **Создай Web Service в [https://render.com](https://render.com):**
   - Выбери "Deploy from GitHub"
   - Укажи этот репозиторий
   - Всё остальное Render сделает сам

4. **Открой ссылку вида:**
   ```
   https://kitchen-dashboard.onrender.com
   ```

Данные будут обновляться автоматически:
- Продажи: каждые 60 секунд
- Столы: каждые 30 секунд
- Бронирования: каждые 10 минут
- Статус света: каждые 5 минут

## 💡 Статус світла

Дашборд показує компактну інформацію про відключення світла для **групи 3.2** (Софіївська Борщагівка, вул. Миру 36):

- 🟢 **Є світло** + час до відключення
- 🔴 **Немає світла** + час до включення  
- ❓ **Дані недоступні** (якщо API тимчасово недоступне)

Використовується офіційний API від Yasno (ДТЕК) для Київської області з автоматичною фільтрацією по групі 3.2.
